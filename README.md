# Interactive Quote & Proposal Builder

A monorepo with a **Next.js** frontend and an **Express** backend. Pricing lives in **Airtable**; the API calculates quote totals server-side and never trusts prices from the client.

```
quotely/
├── frontend/   # Next.js (port 3000)
└── backend/    # Express + Airtable (port 4000)
```

## Prerequisites

- Node.js 18+
- An [Airtable](https://airtable.com) base with the tables below
- Airtable Personal Access Token with access to that base

## Airtable setup

Create a base (or use an existing one) with these tables and fields.  
**Paste your base URL / schema notes here if you want a team reference:**  
`<!-- AIRTABLE_SCHEMA_LINK: https://airtable.com/appXXXXXXXXXXXXXX -->`

### Tables

#### Services

| Field         | Type   | Notes        |
|---------------|--------|--------------|
| Name          | Single line text | Required |
| Description   | Long text          |          |

#### Packages

| Field         | Type   | Notes                          |
|---------------|--------|--------------------------------|
| Name          | Single line text | Required                  |
| Description   | Long text          |                           |
| Price         | Number             | Currency amount            |
| Service       | Link to Services   | Single linked record      |

#### Addons

| Field         | Type   | Notes                          |
|---------------|--------|--------------------------------|
| Name          | Single line text | Required                  |
| Description   | Long text          |                           |
| Price         | Number             | Currency amount            |
| Service       | Link to Services   | Single linked record      |

#### Quotes

| Field         | Type   | Notes                                      |
|---------------|--------|--------------------------------------------|
| QuoteId       | Single line text | UUID generated by the API             |
| ServiceName   | Single line text   | Denormalized for display              |
| PackageName   | Single line text   |                                       |
| PackagePrice  | Number             | Locked at creation                    |
| AddonsJSON    | Long text          | JSON with addons + email/meta         |
| AddonTotal    | Number             |                                       |
| TotalPrice    | Number             | PackagePrice + AddonTotal             |
| CustomerName  | Single line text   | Stored as `Name <email@domain>`       |

> Tip: run `npm run seed:catalog` in `backend/` to load the full professional
> catalog (30 services including **Other / Custom Request**), each with matching
> packages and industry-standard add-ons filtered by the selected service.

## Backend

```bash
cd backend
cp .env.example .env
# Edit .env with AIRTABLE_API_KEY and AIRTABLE_BASE_ID
npm install
npm run dev
```

API runs at **http://localhost:4000**.

| Method | Path                 | Description                          |
|--------|----------------------|--------------------------------------|
| GET    | `/api/pricing`       | Services, packages, and addons       |
| POST   | `/api/quotes`        | Create quote (server-side pricing)   |
| GET    | `/api/quotes/:quoteId` | Fetch a saved quote                |

Airtable credentials stay in `backend/.env` only. The frontend never sees them.

## Frontend

```bash
cd frontend
cp .env.example .env.local
# Optional: set NEXT_PUBLIC_API_URL (defaults to http://localhost:4000)
npm install
npm run dev
```

App runs at **http://localhost:3000**.

## Run both (required)

Use **two terminals**:

```bash
# Terminal 1
cd backend && npm run dev

# Terminal 2
cd frontend && npm run dev
```

1. Open http://localhost:3000  
2. Start a quote → service → brief → package (or skip) → add-ons → contact  
3. Open the proposal, download PDF, or **Submit proposal** to email your team + confirm the client  

### Email setup (proposal submit)

Uses [EmailJS](https://www.emailjs.com) from the backend (`@emailjs/nodejs`).  
No file attachments (works on the free tier).

On submit:

- **You** get an email with the full proposal details inlined in the body  
- **The client** gets a short confirmation email  

1. Create an EmailJS account and connect an email service  
2. Create **two Email (HTML) templates**:

**Owner template**

| Field | Value |
|-------|--------|
| To Email | `{{to_email}}` |
| Reply To | `{{reply_to}}` |
| Subject | `{{subject}}` |
| Body | `{{{message_html}}}` |

**Client template**

| Field | Value |
|-------|--------|
| To Email | `{{to_email}}` |
| Subject | `{{subject}}` |
| Body | `{{{message_html}}}` |

3. Under **Account → Security**, enable API requests for non-browser apps  
4. Add to `backend/.env`:

```
EMAILJS_SERVICE_ID=service_xxxxxxx
EMAILJS_PUBLIC_KEY=xxxxxxxx
EMAILJS_PRIVATE_KEY=xxxxxxxx
EMAILJS_OWNER_TEMPLATE_ID=template_xxxxxxx
EMAILJS_CLIENT_TEMPLATE_ID=template_xxxxxxx
OWNER_EMAIL=you@yourdomain.com
```

Restart the backend after changing `.env`.
